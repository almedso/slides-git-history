# Git History

Slides - that explain the importance of git history and how it needs to be
to get the most out of it


Exercises - that support ending up with a long commit chain without diamands
and fine granular atomic commits

## Usage

Browse the slides on the web at

[https://almedso.github.io/slides-git-history/](https://almedso.github.io/slides-git-history/)


### Local

Install reveal-md
```sh
npm install -g reveal-md
```


Run the slides locally with:

```sh
reveal-md --preprocessor preproc.js slides.md
```
